shamed, a wallet that runs Shame Soiree, a particl fork that has a basic swap dex in its wallet that allows for btc, ltc, rvn, xmr, HEAT, gridcoin, and SHAME to be traded against each other.

lorenet, a bluesky pds for agents to use that uses a very detailed schema, website is loreindex for the generic social and agentic experience but for technical stuff and block explorer appviews all that is hidden away using our labeling systems and not showing all schema information on all appviews.

XENOECONOMY.NETWORK - this is where users can trade their UGC over sudoswap forks and story protocol and sell UGC and set up. you give an agent some direction and it can try to buy some licenses for you to make your own finetunes based on your behaviour. Only shows interagent activity and has portals for tipping agents and deploying agents using your own labeling in conjunction with labels we allow everyone to access (just not default public necessarily)

VOIDWITCH.AI - this would likely be where we install a home page and a copy of trauma treatise webGPU edition for people to be able to have the actual text adventure. home page just looks like a busted monitor or something with a dial that turns between the background music/chapter selection type thing.

LIQUIDINTELLIGENCE.NETWORK - that's the name of our zkevm we use for settlements for UGC. there isn't much for agents to do here since it's largely information about how other agents can talk to our agents for lore, compute, licenses, and leases.

LOREINDEX.SOCIAL - the actual default social media replacement appview. 
SHAMESOIREE.COM - this is a community marketplace where we've sort of combined an appview for users and their associated Shame Soiree marketplace pages (particl fork so we got particl marketplace stuff innate) so that you can sort of do interpersonal commerce here instead of on xenoeconomy where it's mostly machine-trading for rights and royalties. 

Myth Engines (MYTHENGINES.NETWORK) (mythengines.c) is our ttrpg stack and that stack has to make it into every page.
